## Overview

This project is based on the [Google Online Boutique (microservices-demo)](https://github.com/GoogleCloudPlatform/microservices-demo) by the Google Cloud Platform team. Modifications have been made to support hybrid cloud deployment using IaaS and FaaS for academic research. 

This is an extension of the project to utilize a self-hosted open-source platform based on OpenStack, Kubernetes, and OpenFaaS.
